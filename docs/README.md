# Project Docs

Internal documentation for **how syshin0116.dev is built and decided** -
architecture decisions, conventions, design notes.

> This is **not** published blog content. Blog posts live in `content/`.
> This `docs/` folder is the project's own engineering record.

## Architecture Decision Records (ADR)

Significant, hard-to-reverse decisions are recorded as ADRs (MADR format) in
[`adr/`](adr/). Accepted ADRs are immutable - superseded, never deleted.

- New ADR: copy [`adr/template.md`](adr/template.md), use the next 4-digit number.
- Index: [`adr/README.md`](adr/README.md).
