## Section 1 — Folder restructuring

**Decision: No folders introduced.**

### Topical clusters observed

| Cluster | Pages | Verdict |
|---------|-------|---------|
| AI/ML fundamentals | ai-기초개념, transformer-architecture, object-detection | 3 pages; clean grouping but `ai` tag already spans ~14 pages — a folder would look like a subset while leaving the rest homeless |
| PKM tools | zettelkasten, obsidian-notion-sync, quartz-publishing, second-brain-rag | 4 pages; quartz-publishing is equally a "blog publishing" page — boundary is fuzzy |
| DevOps/infra | docker, git-basics, github-actions-gcp-cicd, ubuntu-server-setup | 4 pages; git-basics is version control, not infra — grouping is real but has blurry edges |
| Blog/publishing | static-site-generators, quartz-publishing, blog-seo | 3 pages; quartz-publishing also belongs in PKM cluster |
| Certifications | 빅분기-실기, 정보처리기사 | 2 pages; unmistakably distinct from everything else, but too thin for a folder |
| Personal projects | clidex, cli-ux-design, misen | 3 pages sourced from content/Projects/; source origin ≠ topical folder |
| AI tools | langflow, misen, moonlight-ai, cursor-project-rules, clidex | 5 pages; already captured in `type: tool`; wildly different domains |

### Why no folders at 26 pages

1. **Scale doesn't require it.** 26 pages in a flat list fits on one screen. No navigation friction to solve.
2. **Every cluster has a blurry edge.** quartz-publishing is both PKM and blog-publishing. misen is a personal project and an AI tool. vibe-coding is a concept about AI-assisted coding. Forcing folder assignments would be arbitrary.
3. **`type:` already provides one structural layer.** concept/reference/pattern/tool gives readers a mental filter. Folders that roughly mirror `type:` add noise without value.
4. **Certifications (2 pages) is the most justified grouping** — cleanly distinct, unmistakable label — but 2 pages is too thin, and readers will search by exam name, not browse a certifications/ folder.
5. **Wikilinks resolve by basename regardless of folder.** Folder moves carry no technical benefit. At 26 pages, browsability gain is zero.

### Threshold for revisiting

- Any coherent topical cluster reaches 6+ pages with clean membership (no cross-cluster ambiguity), **or**
- Flat list grows past ~40 pages and becomes impractical to scan.
- Certifications specifically: introduce a `certifications/` folder when a 3rd exam guide is ingested.
